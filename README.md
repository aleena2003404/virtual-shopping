# Virtual Shopping Platform 

##  Project Overview

Virtual Shopping Platform is a Django-based web application developed for online shopping. It allows users to browse products, view details, and manage shopping activities in a simple and user-friendly interface.

---

##  Objective

The main objective of this project is to create a basic e-commerce platform where users can easily view and explore products in an organized way.

---

##  Technologies Used

* Python 
* Django Framework
* HTML5
* CSS3
* Bootstrap
* SQLite Database

---

##  Features

* Product Category Management
* Product Listing Page
* Product Detail View
* Image Upload Support
* Responsive UI Design
* Navigation System

##  Installation Steps

1. Clone the repository

```bash
git clone https://github.com/aleena2003404/virtual-shopping.git
```

2. Move into project folder

```bash
cd virtual-shopping
```

3. Create virtual environment

```bash
python -m venv venv
```

4. Activate virtual environment

```bash
venv\Scripts\activate
```

5. Install dependencies

```bash
pip install -r requirements.txt
```

6. Run migrations

```bash
python manage.py migrate
```

7. Start server

```bash
python manage.py runserver
```
