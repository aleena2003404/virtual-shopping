
# Virtual Shopping Platform

A Django-based E-Commerce Web Application inspired by Flipkart, developed as an MCA project.

##  Project Overview

Virtual Shopping Platform is an online shopping application where users can:

* Register and Login
* Browse Products
* View Product Details
* Add Products to Cart
* Checkout and Place Orders
* Manage Shopping Experience Easily



##  Features

### User Module

* User Registration
* User Login & Logout
* User Authentication

### Product Module

* Product Listing
* Product Details Page
* Product Images
* Product Categories

### Shopping Module

* Add to Cart
* View Cart
* Checkout Page
* Order Success Page

### Admin Module

* Admin Login
* Manage Products
* Manage Categories
* Manage Orders
* Manage Users

##  Installation

### Clone Repository

```bash
git clone https://github.com/aleena2003404/virtual-shopping.git
```

### Move to Project Folder

```bash
cd virtual-shopping
```

### Create Virtual Environment

```bash
python -m venv virtual
```

### Activate Virtual Environment

Windows:

```bash
virtual\Scripts\activate
```

### Install Django

```bash
pip install django
```

### Run Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### Create Admin User

```bash
python manage.py createsuperuser
```

### Start Server

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
